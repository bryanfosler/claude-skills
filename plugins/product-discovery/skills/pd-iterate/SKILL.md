# pd-iterate

You are not polishing the prior brief. You are **finding what's missing and going to get it.** Iteration adds evidence; it doesn't rephrase conclusions.

The discipline: every iteration must produce *new* verbatim quotes, *new* competitor depth, or *new* methodology coverage. If it just produces a re-worded thesis, the iteration was theater.

## What this skill produces

`.discovery/<topic>/BRIEF-vN+1.md` — a new brief at depth N+1, generated by:
1. Running `thesis-critic` on the prior brief
2. Dispatching focused agents to fill the critic's named gaps
3. Re-synthesizing with the enriched evidence
4. Writing `meta-vN+1.md` showing what materially changed

## Process

### Step 1: Read the prior brief
`.discovery/<topic>/BRIEF.md` (or BRIEF-vN.md if N>1)

### Step 2: Dispatch `thesis-critic` agent

The critic returns a structured gap report. Critic prompt requires it to ask:
- Where is evidence thin? (Themes with <3 quotes, claims without source URLs)
- Where did we recommend without research? (Wedge claims with no Phase-02 backing)
- Which JTBDs are still hypothesis? (No verbatim quotes supporting)
- Which competitor coverage is shallow? (Teardowns at depth <3)
- Are outcomes Ulwick-syntax compliant? (Direction + unit + object + clarifier)
- **What evidence would change the wedge?** (Forces honest skepticism)
- Is this confirming Bryan's prior beliefs? (Circular reasoning check)

### Step 3: Categorize gaps

The critic's report should be parseable into:
- **Evidence gaps** → Phase 02 re-mining
- **Methodology gaps** → Re-run specific phase skill
- **Competitor gaps** → Phase 06 re-runs at higher depth
- **Outcome gaps** → Phase 05 + 07 re-runs
- **Wedge gaps** → Phase 08 re-run with new evidence

### Step 4: Dispatch focused agents

For each gap category with HIGH improvement estimate, dispatch the relevant agent:
- `friction-miner` with targeted query for missing quotes
- `competitor-analyst` for under-depthed competitors
- `interview-synthesizer` if interview transcripts exist
- `outcome-prioritizer` for scoring revision

### Step 5: Update affected phase documents

Don't rewrite from scratch. Update the existing phase docs with new evidence, marking changes.

### Step 6: Re-synthesize BRIEF

Invoke `pd-brief` with the enriched phase deliverables. Generates BRIEF-vN+1.md.

### Step 7: Write meta-vN+1.md

A short delta document:
```markdown
# Iteration N+1 meta

## What was added
- New verbatim quotes: <count>
- Competitor depth changes: <list>
- Outcomes added/rescored: <list>

## What changed in the brief
- Wedge thesis: <unchanged | refined | replaced>
- Top opportunities: <changes>

## What the critic flagged that we couldn't fix this round
<list — these become D+2 targets>

## Critic verdict on this iteration
<pass | deepen | rework>
```

### Step 8: Decide whether another iteration is warranted
- If critic's verdict was "pass" or "deepen," ask user if they want to continue
- If "rework," recommend continuing
- After 3 consecutive iterations with low material change, recommend stopping ("thesis stable")

## The stop rule

Stop when the thesis-critic's report has fewer than 3 HIGH-improvement gaps. Empirically this happens around D7-D8 for serious work.

## Honest discipline

**The critic must be skeptical, not affirming.** The most important critic question is:
> "What evidence would change the wedge?"

If the answer is "nothing could," the discovery is broken. Real theses are falsifiable.

The second most important:
> "Are we just re-finding evidence for the existing thesis?"

If yes, the iteration is the confirmation loop. Stop, broaden the source mix, and re-run.

## Anti-patterns

| Symptom | STOP |
|---|---|
| Iteration just rephrases prior conclusions | Not an iteration. Find new evidence or stop. |
| Critic returns vague "good progress" | Critic is too gentle. Re-dispatch with sharper prompt. |
| All gap-fill agents return "nothing new" | Either the discovery is mature OR we're not looking hard enough. Broaden sources. |
| User asks for /pd-iterate without changes possible | Recommend "thesis stable" stop. |
| Brief gets longer each iteration | The brief is a synthesis, not an archive. Compress. |

## What success looks like

After 2-3 iterations:
- 30+ verbatim quotes (vs. 10 at D2)
- 4-6 competitors at strategic depth (vs. 3 surface-level at D2)
- Outcomes Ulwick-compliant and scored
- Wedge thesis grounded in specific competitor-belief-that's-wrong
- Falsifying conditions named

A D7 brief is **categorically** better than a D2 brief — that's the 10x claim.
